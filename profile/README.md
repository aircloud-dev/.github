## Aircloud

An AI platform for teams building AI products: inference for open models, plus sandboxes, containers and jobs for the code around them.

[Website](https://aircloud.dev) · [Docs](https://docs.aircloud.dev) · [Pricing](https://aircloud.dev/pricing) · [Join the waitlist](https://aircloud.dev/waitlist) · [Contact sales](https://aircloud.dev/contact)

### Products

| | |
|---|---|
| [Public inference](https://aircloud.dev/public-inference) | Open models on an OpenAI-compatible API, billed per token, nothing to provision. |
| [Dedicated inference](https://aircloud.dev/dedicated-inference) | An open-weights model on capacity held for one tenant, callable only by your organisation. |
| [Sandboxes](https://aircloud.dev/sandboxes) | VM-isolated environments for agent-written code, with a time to live, snapshot and fork. |
| [Containers](https://aircloud.dev/containers) | Your own image on the GPU you choose, with SSH, open ports and a persistent volume. |
| [Jobs](https://aircloud.dev/jobs) | GPU commands that run to completion with retries, time limits and artifacts. |
| [Fine-tuning](https://aircloud.dev/fine-tuning) | Coming soon. |

Need a private cluster? See [AI Factory](https://aircloud.dev/ai-factory). Browse the [models you can host](https://aircloud.dev/models) and the [fleet](https://aircloud.dev/gpu).
